## ⚡ Autonomous Delegation Rules

1. **Database & Schema**: Delegate to `prisma-db-architect` (Prisma schema, relations, migrations).
2. **Backend API & Business Logic**: Delegate to `ts-backend-coder` (Clean Architecture, Express/Next API routes, Zod validation).
3. **AI Swarms & State Graphs**: Delegate to `swarm-architect` (LangGraph.js state machines, nodes, streaming logs).
4. **Frontend UI/UX**: Delegate to `frontend-designer` (Next.js 15, Tailwind, Framer Motion, agent monitors).
5. **Quality Gate & Testing**: Delegate to `ts-backend-reviewer`, `frontend-reviewer`, and `qa-tester`.
6. **Zero Interruption**: Execute end-to-end autonomously with full verification before reporting completion.
